# 创业路·价值判断 + 三区结构 — HTML 演讲稿

## 如何打开

1. 用 Chrome / Edge / Safari 打开 `index.html`（支持 `file://`）。
2. 翻页：键盘 `←` `→` / `空格`，或底部导航与圆点。
3. Google Fonts（Noto Serif SC、Inter）需联网；离线回退系统宋体 / PingFang / 微软雅黑。
